🤖 Agent 功能
================================================================================

内置工具:

  1. 时间工具 (use_tool_time)
     触发词: "时间", "现在", "几点"
     功能: 获取当前时间
     例子: "现在几点了？"

  2. 搜索工具 (use_tool_search)
     触发词: "查询", "搜索", "关于", "什么"
     功能: 知识库搜索
     例子: "什么是 LangGraph?"

  3. 计算工具 (use_tool_calculate)
     触发词: "计算", "算", "等于"
     功能: 数学表达式计算
     例子: "计算 10+5*2"

Agent 流程:

  START
    ↓
  [处理输入]
    ↓
  [思考和规划]
    ├→ 询问时间? → [获取时间]
    ├→ 要搜索? → [知识库搜索]
    ├→ 要计算? → [数学计算]
    └→ 其他 → [通用回复]
    ↓
  [生成响应]
    ↓
  END
