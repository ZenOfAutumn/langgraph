💡 核心要点
──────────────────────────────────────────────────────────────────────────────

1. 什么是 Checkpoint?
   └─ 图执行过程中的状态快照
   └─ 每个节点执行完都会自动保存

2. 为什么重要?
   ├─ 🛡️  故障恢复 - 从上次中断点继续
   ├─ ⚡ 效率提升 - 避免重复执行
   ├─ 📊 可观测性 - 清晰追踪进度
   └─ 🔄 支持并发 - 多流程独立运行

3. 如何使用?
   ├─ 初始化 checkpointer（SQLite/PostgreSQL）
   ├─ 编译图时启用 checkpointer
   ├─ 使用 thread_id 标识流程
   └─ 执行时自动保存和恢复

4. thread_id 的作用
   └─ 是流程的唯一标识
   └─ 相同 thread_id 共享 checkpoint
   └─ 不同 thread_id 完全独立

🔧 技术细节
──────────────────────────────────────────────────────────────────────────────

Checkpoint 存储选项：

开发环境：SQLite
✓ 安装简单
✓ 无需额外服务
✗ 并发支持有限

生产环境：PostgreSQL
✓ 高并发支持
✓ 数据可靠性高
✓ 支持分布式系统

自定义存储：
✓ 实现 BaseSaver 接口
✓ 可连接任何数据库或存储系统

数据流向：
节点执行完 → 生成新状态 → LangGraph 调用 checkpointer.put()
                          → 状态保存到数据库

故障恢复：
系统重启 → 使用相同 thread_id 执行
        → LangGraph 调用 checkpointer.get()
        → 从最后一个状态继续

📈 性能特征
──────────────────────────────────────────────────────────────────────────────

Checkpoint 操作开销：
• 保存操作：数据库 IO（毫秒级）
• 恢复操作：数据库查询（毫秒级）
• 整体影响：< 5% 性能开销（通常）

优化建议：
• 使用连接池
• 定期清理旧 checkpoint
• 在关键节点处设置 checkpoint
• 使用 PostgreSQL（生产环境）

💾 数据库结构
──────────────────────────────────────────────────────────────────────────────

Checkpoint 表中的数据：

┌──────────────┬──────────────┬────────────┬──────────────┐
│ thread_id    │ checkpoint_id│ values     │ metadata     │
├──────────────┼──────────────┼────────────┼──────────────┤
│ ORDER-001    │ 1            │ {state...} │ {ts, node..} │
│ ORDER-001    │ 2            │ {state...} │ {ts, node..} │
│ ORDER-002    │ 1            │ {state...} │ {ts, node..} │
└──────────────┴──────────────┴────────────┴──────────────┘

• 每个 thread_id 有多个 checkpoint
• 每个 checkpoint 保存完整的状态快照
• 按时间顺序记录执行历史

📞 快速问题解答
──────────────────────────────────────────────────────────────────────────────

Q: Checkpoint 会让系统变慢吗？
A: 有轻微影响（<5%），但好处远大于成本

Q: 多少个 thread_id 会有性能问题？
A: SQLite: 1-10 个，PostgreSQL: 10000+ 个

Q: 如何手动清理旧 checkpoint？
A: checkpointer.clean(config) 或直接删除数据库中的数据

Q: 能否在中途暂停和恢复流程？
A: 可以，通过相同 thread_id 重新执行即可

Q: 状态中包含敏感信息怎么办？
A: 使用加密存储或自定义 checkpointer
